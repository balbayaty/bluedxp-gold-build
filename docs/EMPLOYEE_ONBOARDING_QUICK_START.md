# 🚀 EMPLOYEE ONBOARDING - QUICK START

## 📋 How It Works

### **For Admins:**

1. **Invite Employee:**
   - Go to Billing Dashboard
   - Click "Invite Employee" (if on company plan)
   - Fill in employee details
   - Send invitation

2. **Approve Employee:**
   - Receive notification (email + in-app)
   - Go to `/admin/approve-employee`
   - Review employee request
   - Click "Approve" or "Reject"

### **For Employees:**

1. **Receive Invitation:**
   - Get email with invitation link
   - Click link to go to signup page

2. **Complete Signup:**
   - Fill in name, password
   - Complete profile (optional)
   - Submit form

3. **Start Using:**
   - Account created
   - Linked to company subscription
   - Can access system immediately

---

## 🔗 Quick Links

- **Employee Signup**: `/signup?token=[invitation-token]`
- **Admin Approval**: `/admin/approve-employee`
- **Billing Dashboard**: `/billing`

---

## ⚙️ Settings

**Enable/Disable Approval:**
- Setting: `employee.approval.enabled`
- Default: `true` (approval required)
- If `false`: Auto-approves invitations
