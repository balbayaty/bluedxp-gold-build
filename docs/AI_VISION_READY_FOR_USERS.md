## 🔧 **API USAGE**

### **Basic Analysis:**
```bash
curl -X POST http://your-domain/api/ai/vision \
  -F "image=@photo.jpg" \
  -F "context=Quality inspection"
```

### **Agent-Based Analysis:**
```bash
curl -X POST http://your-domain/api/ai/vision/agent \
  -H "Content-Type: application/json" \
  -d '{
    "type": "analysis",
    "imageFile": "base64...",
    "context": "Safety check",
    "module": "qhse"
  }'
```

### **Health Check:**
```bash
curl http://your-domain/api/ai/vision/health
```
