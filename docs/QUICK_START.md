# ⚡ QUICK START - User Management System

## 🚀 3-Step Setup (5 Minutes)

### Step 1: Run Setup Script

**Windows:**
```powershell
npm run setup:user-management:ps1
```

**Linux/macOS:**
```bash
npm run setup:user-management:sh
```

**All Platforms:**
```bash
npm run setup:user-management
```

### Step 2: Seed Initial Data (Optional)

```bash
npm run seed:user-management
```

This creates:
- ✅ System permission templates
- ✅ Default roles
- ✅ Default tenant (if needed)

### Step 3: Start Application

```bash
npm run dev
```

Visit: **http://localhost:3002/settings/users**

## 🎯 What You Can Do Now

### 1. Create Users
- Click "Create User"
- Fill in email, name, role
- Assign customers (hierarchical support)
- Set data visibility rules

### 2. Manage Roles
- Go to "Roles" tab
- Create custom roles
- Use role templates
- Set role inheritance

### 3. Set Permissions
- Use Permission Matrix
- 5-level hierarchy (Module → Feature → Tab → Action → Field)
- Use AI Assistant for recommendations
- Set permission scopes

### 4. Generate API Keys
- Go to "API Keys" tab
- Generate new keys
- Set scopes and rate limits
- Rotate keys

### 5. View Analytics
- Go to "Analytics" tab
- View user activity
- Permission usage
- Security metrics
