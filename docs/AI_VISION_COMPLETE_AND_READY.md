## 📋 **DEPLOYMENT STEPS**

### **1. Database Migration (Required)**
```bash
npx prisma migrate deploy
```

### **2. Environment Variables (Required)**
```env
DATABASE_URL=postgresql://user:password@localhost:5432/bluedxp
DATABASE_TYPE=postgresql
NEXT_PUBLIC_OPENAI_API_KEY=your_key (optional)
NEXT_PUBLIC_ANTHROPIC_API_KEY=your_key (optional)
```

### **3. Verify Health**
```bash
curl http://localhost:3000/api/ai/vision/health
```

### **4. Start Using**
Navigate to `/ai-vision` and start analyzing!
