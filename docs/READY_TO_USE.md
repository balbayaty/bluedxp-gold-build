## 🚀 QUICK START (3 STEPS)

### Step 1: Generate Prisma Client (One-Time)

**If you see a file lock error:**
1. Stop all running processes (dev server, Prisma Studio, etc.)
2. Close your IDE temporarily
3. Run:
   ```bash
   npx prisma generate
   ```

**Note:** The system will work even if Prisma client generation fails - it uses raw SQL queries as a fallback.

### Step 2: Start the Application

```bash
npm run dev
```

### Step 3: Access the UI

Visit: **http://localhost:3002/settings/users**

## ⚠️ KNOWN ISSUE (Non-Critical)

**Prisma Client Generation File Lock**

This is a Windows-specific issue where a file is locked by another process. The system will still work because it uses raw SQL queries as a fallback.

**To fix:**
1. Stop all running processes
2. Close your IDE
3. Run: `npx prisma generate`

**The system is fully functional even without this step!**
