## 🎯 Executive Summary

### What We Need to Integrate

**Customs Portals & Systems:**
- **Egypt**: NAFEZA, CargoX (ACID system)
- **Saudi Arabia**: FASAH (ZATCA)
- **UAE**: Dubai Trade / Mirsal
- **Kuwait**: ASYCUDA World
- **Qatar**: Al Nadeeb
- **Bahrain**: Sijilat
- **Oman**: Bayan
- **Jordan**: ASYCUDA World
- **Lebanon**: (Under development)

**Regulatory Bodies:**
- Each country has multiple regulatory authorities (Food & Drug, Standards, Trade, etc.)
- Some require separate integrations (e.g., SFDA in Saudi, Civil Defense)

### Integration Difficulty: **MODERATE to EASY** ✅

**Why it's manageable:**
- ✅ We already have an **Adapter Pattern** architecture
- ✅ We have examples (Rabet.sa, Maersk, FedEx)
- ✅ Most systems use REST APIs
- ✅ Unified interface already exists (`TransportationAdapter`)

**Challenges:**
- ⚠️ Each country has different authentication methods
- ⚠️ Some require certificates (not just API keys)
- ⚠️ Documentation may be in Arabic
- ⚠️ Some systems are still being developed

## 🌍 Country-by-Country Breakdown

### 🇪🇬 **EGYPT** - Priority #1

#### Systems Required:
1. **NAFEZA** (National Single Window)
   - **Purpose**: Main customs portal
   - **Type**: Government platform
   - **Integration**: API available
   - **Difficulty**: ⭐⭐⭐ (Moderate)

2. **CargoX** (Blockchain Document Platform)
   - **Purpose**: Document submission for ACID
   - **Type**: Third-party platform (blockchain-based)
   - **Integration**: REST API + Blockchain
   - **Difficulty**: ⭐⭐⭐⭐ (More complex - blockchain)

3. **ACID System** (Advance Cargo Information Declaration)
   - **Purpose**: Pre-arrival cargo information
   - **Type**: Mandatory requirement
   - **Integration**: Via CargoX + NAFEZA
   - **Difficulty**: ⭐⭐⭐ (Moderate)

#### Requirements:
- ✅ **Registration**: Exporters must register on CargoX (USD 15 fee)
- ✅ **ACID Number**: Generated by importer on NAFEZA
- ✅ **Document Upload**: Must upload 48 hours before arrival
- ✅ **Mandatory**: Sea freight (now), Air freight (Jan 2026)

#### Integration Steps:
1. Register company on CargoX
2. Get API credentials from CargoX
3. Get API credentials from NAFEZA
4. Create `CargoXAdapter.ts`
5. Create `NafezaAdapter.ts`
6. Link them together for ACID workflow

**Estimated Time:** 5-7 days

## 🛠️ Technical Implementation Guide

### Step 1: Create Adapter Structure

For each country, create:

```
lib/adapters/customs/
├── egypt/
│   ├── CargoXAdapter.ts
│   ├── NafezaAdapter.ts
│   └── types.ts
├── uae/
│   ├── DubaiTradeAdapter.ts
│   ├── MirsalAdapter.ts
│   └── types.ts
├── kuwait/
│   └── ASYCUDAAdapter.ts
└── ... (other countries)
```

### Step 2: Implement TransportationAdapter Interface

**Example Structure:**

```typescript
// lib/adapters/customs/egypt/CargoXAdapter.ts
import { TransportationAdapter } from '@/lib/adapters/transportation/base/TransportationAdapter'

export class CargoXAdapter implements TransportationAdapter {
  readonly id = 'cargox'
  readonly name = 'CargoX (Egypt ACID)'
  readonly type = 'CUSTOMS' as const

  async isConnected(): Promise<boolean> {
    // Check API connection
  }

  async submitCustomsDeclaration(declaration: Partial<CustomsInfo>): Promise<CustomsInfo> {
    // Submit ACID documents via CargoX
  }

  // ... implement other required methods
}
```

### Step 3: Register in Adapter Manager

```typescript
// In adapter initialization
import { CargoXAdapter } from '@/lib/adapters/customs/egypt/CargoXAdapter'
import { adapterManager } from '@/lib/adapters/transportation'

const cargoxAdapter = new CargoXAdapter({
  apiKey: process.env.CARGOX_API_KEY,
  // ... other config
})

adapterManager.register('cargox', cargoxAdapter)
```

### Step 4: Add to UI

Update integration settings page to show new customs adapters.

## 🎯 Quick Start: Egypt Integration (Example)

### Step 1: Get Credentials

1. Register on CargoX: https://cargox.io
   - Pay USD 15 verification fee
   - Get API key

2. Register on NAFEZA: https://nafeza.gov.eg
   - Get business credentials
   - Get API access

### Step 2: Add to Environment Variables

```bash
# .env
CARGOX_API_KEY=your_key_here
CARGOX_API_SECRET=your_secret_here
NAFEZA_API_URL=https://api.nafeza.gov.eg
NAFEZA_USERNAME=your_username
NAFEZA_PASSWORD=your_password
```

### Step 3: Create Adapters

We'll create:
- `lib/adapters/customs/egypt/CargoXAdapter.ts`
- `lib/adapters/customs/egypt/NafezaAdapter.ts`

### Step 4: Test

Go to `/transportation/integration` and test the connection!
