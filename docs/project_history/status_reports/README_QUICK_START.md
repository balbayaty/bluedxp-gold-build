# 🚀 BlueDXP Platform - Quick Start (Copy & Paste)

## Fastest Way to Get Started

### 1. Check Prerequisites
```bash
npm run check:deps
```

### 2. Run Setup
**Windows:**
```powershell
npm run setup:windows
```

**Mac/Linux:**
```bash
npm run setup
```

### 3. Start Services
```bash
docker-compose up -d
```

### 4. Verify
```bash
npm run check:connectivity
```

### 5. Open Browser
Go to: **http://localhost:3002**

---

## That's It! 🎉

Your platform is now running!
