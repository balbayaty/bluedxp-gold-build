## 🎯 **JOURNEY ANALYSIS FEATURES**

### **✅ Dynamic Touchpoint Generation**
- Automatically determines touchpoint pattern based on:
  - Origin country (Europe detection)
  - Destination country (Middle East detection)
  - Transport mode (Sea, Air, Multi-Modal)
  - Shipment type and requirements
- Supports waypoints and intermediate stops
- Handles all shipment types (FCL, LCL, FTL, LTL, Air, etc.)

### **✅ Multi-Modal Patterns**
- **Europe → Saudi Arabia (Sea)**: Origin → Export Customs → POL → Transit Port → POD → Import Customs → Destination
- **Europe → UAE (Air)**: Origin → Export Customs → AOD → Transit Airport → AOA → Import Customs → Destination
- **Europe → Middle East (Multi-Modal)**: Origin → Export Customs → Inland Depot → POL → POD → Import Customs → Bonded Warehouse → Destination

### **✅ Industry-Standard Terminology**
- **POL** - Point of Loading
- **POD** - Point of Delivery/Discharge
- **AOD** - Airport of Departure
- **AOA** - Airport of Arrival
- **CFS** - Container Freight Station
- **DEHUB** - Deconsolidation Hub
- **18 Touchpoint Types** - All industry-standard types
- **6 Transport Leg Modes** - Road, Rail, Sea, Air, Barging, Pipeline

### **✅ Document Management**
- Required documents per touchpoint
- Document status tracking
- Export/Import licenses
- Bills of Lading, Air Waybills, CMR
- Certificates (Origin, Health, MSDS, etc.)

### **✅ Root Cause Integration**
- Automatic exception detection from touchpoints
- Bottleneck identification
- Root cause analysis via journey workflow
- Recommendations generation
