## 🚀 **USAGE**

### **Access Warehouse Locations:**
Navigate to `/warehouse-locations` to:
- View all storage locations
- Create new locations with comprehensive form
- Filter by country, compliance, fire system
- View analytics and statistics
- Check AI compliance verification

### **Access Warehouse Areas:**
Navigate to `/warehouse-areas?warehouseId=xxx` to:
- Manage areas and zones
- Track capacity and utilization
- Import/Export areas
- View real-time analytics
- Manage hazard class restrictions

### **API Endpoints:**
- `GET /api/wms/locations` - List locations
- `POST /api/wms/locations` - Create location
- `GET /api/wms/locations/[id]` - Get location
- `PUT /api/wms/locations/[id]` - Update location
- `DELETE /api/wms/locations/[id]` - Delete location
- `GET /api/wms/areas` - List areas
- `POST /api/wms/areas` - Create area (or import)
- `GET /api/wms/areas/export` - Export areas to CSV
- `GET /api/wms/fire-safety?action=specs` - Get fire system specs
- `GET /api/wms/compliance?action=check&locationId=xxx` - Check compliance
