## 🚀 How to Use

### 1. Access the Dashboard
Navigate to `/compliance` in your application to see the comprehensive dashboard.

### 2. Initialize Requirements
The Saudi Arabia requirements are automatically initialized when the module loads.

### 3. Create Compliance Records
```typescript
import { complianceService } from '@/lib/services/compliance'

const record = await complianceService.createComplianceRecord({
  tenantId: 'your-tenant-id',
  requirementId: 'TGA-TRANS-001',
  // ... other fields
})
```

### 4. Perform Compliance Checks
```typescript
await complianceService.performComplianceCheck(record.id)
```

### 5. View Dashboard
```typescript
const dashboard = await complianceService.generateDashboard('tenant-id')
```
