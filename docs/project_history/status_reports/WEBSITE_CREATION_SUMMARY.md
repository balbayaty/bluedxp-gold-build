## 🚀 How to Access

1. **Start the development server:**
   ```bash
   npm run dev
   ```

2. **Access any version:**
   - Executive: http://localhost:3002/bluedxp-executive
   - Innovation: http://localhost:3002/bluedxp-innovation
   - Modules: http://localhost:3002/bluedxp-modules
   - Saudi: http://localhost:3002/bluedxp-saudi

3. **Language Toggle:**
   - Click the language button in the header
   - Switch between English and Arabic
   - RTL automatically applied for Arabic
