## 🚀 **USAGE**

### **Access AI Insights**
1. Navigate to `/qhse/statistics`
2. Select "🤖 AI Insights" from view mode dropdown
3. View:
   - Risk predictions with risk factors
   - Anomaly detections
   - AI recommendations
   - Industry benchmarks

### **API Usage**
```typescript
// Get all intelligent insights
GET /api/qhse/intelligent?type=all&tenantId=xxx

// Get only risk predictions
GET /api/qhse/intelligent?type=risks&tenantId=xxx

// Get only recommendations
GET /api/qhse/intelligent?type=recommendations&customerId=xxx
```
