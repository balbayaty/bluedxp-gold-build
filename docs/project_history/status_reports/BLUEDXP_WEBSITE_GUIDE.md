## 🎨 Design Features (All Versions)

### Common Features Across All Versions:
1. **Bilingual Support** - Full English/Arabic with RTL support
2. **Responsive Design** - Mobile, tablet, desktop optimized
3. **Smooth Animations** - Framer Motion animations
4. **Interactive Elements** - Hover effects, transitions
5. **Modern UI/UX** - Glassmorphism, gradients, modern typography
6. **Dark Theme** - Professional dark backgrounds
7. **Accessibility** - Keyboard navigation, screen reader support

### Technical Stack:
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Charts:** Recharts
- **Icons:** Remix Icons
- **TypeScript:** Full type safety

## 🚀 Quick Start

1. **Start the development server:**
   ```bash
   npm run dev
   ```

2. **Access any version:**
   - Executive: http://localhost:3002/bluedxp-executive
   - Innovation: http://localhost:3002/bluedxp-innovation
   - Modules: http://localhost:3002/bluedxp-modules
   - Saudi: http://localhost:3002/bluedxp-saudi

3. **Language Toggle:**
   - Click the language button in the header
   - Switch between English and Arabic
   - RTL automatically applied for Arabic
