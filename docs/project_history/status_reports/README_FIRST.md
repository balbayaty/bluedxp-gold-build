## 🚀 Fastest Start (3 Commands)

```bash
# 1. Check prerequisites
npm run check:deps

# 2. Run setup (Windows: npm run setup:windows)
npm run setup

# 3. Start services
docker-compose up -d
```

Then open: **http://localhost:3002**
