## 📋 **HOW TO USE**

### **Quick Start:**

1. **Navigate to NCR Management**
   ```
   http://localhost:3000/ncr-management
   ```

2. **Click "Raise New NCR"**
   - Modal opens with smart detection form
   - Auto-detection runs automatically

3. **Verify Detection**
   - Detection banner shows stats
   - Some fields auto-filled (high confidence)
   - Some fields show suggestions (medium confidence)

4. **Test File Upload** (Optional)
   - Upload PDF or image
   - Detection re-runs
   - Fields extracted

5. **Submit Form**
   - Fill remaining required fields
   - Click "Submit"
   - Form submits successfully
