## Quick Access Guide

### To Access API Management:
1. **Via Menu**: Click "Integration" in sidebar → Click "API Management"
2. **Via URL**: Navigate to `/integration/api`
3. **Via Integration Hub**: Go to `/integration` → Click "API Management" card

### To Access API Documentation:
1. **Via API Management Page**: Go to Docs tab → Click "OpenAPI Spec (JSON)" button
2. **Direct URL**: `/api/docs`

### To Manage Webhooks:
1. Go to `/integration/api`
2. Click "Webhooks" tab
3. Click "Create Webhook" button
4. Fill in form and select events
5. Click "Create Webhook"
