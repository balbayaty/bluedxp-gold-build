## 🎯 What is Node.js?

**Node.js** is a **runtime environment** that lets you run JavaScript on the **server** (backend), not just in the browser.

### Think of it this way:
- **JavaScript in Browser** = Frontend (what users see)
- **Node.js** = JavaScript on Server (backend logic, APIs, database)

### Your Current Stack:
```
┌─────────────────────────────────────┐
│  Your Hazalyze App                  │
├─────────────────────────────────────┤
│  Frontend: React (JavaScript)       │  ← What users see
│  Backend: Node.js (JavaScript)      │  ← Server logic
│  Framework: Next.js                 │  ← Uses both!
│  Language: TypeScript              │  ← Better JavaScript
└─────────────────────────────────────┘
```

**Node.js is REQUIRED** for Next.js - you can't use Next.js without it!
