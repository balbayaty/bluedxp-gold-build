# 🚀 Quick Setup Guide - Hazalyze ASN Module

## Step-by-Step Instructions

### Step 1: Open Terminal in Project Folder
1. Navigate to: `C:\Users\balba\hazalyze-asn-module`
2. Right-click in the folder and select "Open in Terminal" or "Open PowerShell here"

### Step 2: Install Dependencies
Copy and paste this command in your terminal:
```bash
npm install
```
**Wait for this to complete** - it may take 2-3 minutes. You'll see a progress bar.

### Step 3: Start the Development Server
Once installation is complete, run:
```bash
npm run dev
```

### Step 4: Open in Browser
1. You'll see a message like: "Ready on http://localhost:3000"
2. Open your web browser (Chrome, Edge, Firefox, etc.)
3. Go to: `http://localhost:3000`
4. You should see the Enhanced ASN Module!

## What You'll See

### ✨ Features Available:
- **4 View Modes**: Table, Grid, Analytics (Charts), and Map
- **Search Bar**: Search by ASN ID, shipment number, supplier, or tracking number
- **Statistics Cards**: Total shipments, in-transit, delivered, and compliance rate
- **Filters**: Filter by status, priority, and compliance
- **Interactive Charts**: Pie charts, bar charts, and line graphs
- **Map View**: Visual representation of shipment locations

### 🎨 Design Features:
- **Dark Theme**: Black background with glassmorphism effects
- **Smooth Animations**: Hover effects and transitions
- **Responsive**: Works on desktop, tablet, and mobile
- **Modern UI**: Following Hazalyze design system

## Troubleshooting

### If you get an error about Node.js:
- Make sure Node.js is installed
- Download from: https://nodejs.org/
- Install the LTS (Long Term Support) version

### If npm install fails:
- Make sure you have internet connection
- Try running: `npm install --legacy-peer-deps`

### If the page doesn't load:
- Make sure the terminal is still running (don't close it)
- Check that port 3000 is not being used by another program
- Try refreshing the browser page
