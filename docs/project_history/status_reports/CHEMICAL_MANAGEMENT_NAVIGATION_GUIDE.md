## 🖱️ **How to Access**

### **Method 1: Sidebar Navigation**
1. Look at the **left sidebar** in the application
2. Find **"Chemical Management"** (flask icon 🧪)
3. Click to expand the menu
4. Click on any module to navigate

### **Method 2: Direct URL**
- Type the URL directly in your browser (e.g., `/chemical-database`)
- Or use the browser's address bar

### **Method 3: Search (if available)**
- Use the search functionality to find modules by name
