## 🚀 **How to Use**

### **Grouping**:
1. Click any grouping button (Manufacturer, Hazard, Date, Customer, Status)
2. Submissions will be grouped accordingly
3. Click group header to expand/collapse
4. Click same button again to disable grouping

### **Export**:
1. Click "Export Excel" or "Export CSV" button
2. File will download automatically
3. Includes all displayed submissions with customer data

### **Customer Tracking**:
1. Enter customer name (optional)
2. Enter sub-customer name (optional)
3. All uploaded files will be tagged with this information
4. Information appears on cards and in exports/emails

### **Duplicate Detection**:
1. Automatic - runs after MSDS analysis
2. Shows badge on card if duplicate found
3. Shows notification with recommendation
4. Auto-approves high-confidence exact matches

### **Email Reports**:
1. Automatic - sent when approving/rejecting
2. Professional HTML format
3. Includes all product and customer information
4. Safety recommendations included
