## 🎓 USAGE GUIDE

### For Users

1. **Getting Started**
   - Go to Settings → Accessibility & UX → Adaptive Accessibility
   - Enable accessibility system
   - Choose a quick profile OR customize manually
   - Settings apply immediately

2. **Customization**
   - Use tabs to navigate categories
   - Adjust sliders for precise control
   - Toggle features on/off
   - See changes in real-time

3. **Profiles**
   - Click any quick profile to apply
   - Profiles are ML-optimized
   - Can customize after applying

4. **Import/Export**
   - Export your settings to share or backup
   - Import settings from another user
   - Settings are JSON format

### For Developers

1. **Using the Hook**
   ```typescript
   import { useAccessibility } from '@/contexts/AccessibilityContext'
   
   function MyComponent() {
     const { preferences, updatePreferences } = useAccessibility()
     
     // Access preferences
     if (preferences.focus.adhdMode) {
       // Apply ADHD-friendly features
     }
     
     // Update preferences
     updatePreferences({
       visual: { fontSize: 120 }
     })
   }
   ```

2. **Tracking Events**
   ```typescript
   const { trackEvent } = useAccessibility()
   
   trackEvent({
     type: 'feature_used',
     data: { feature: 'my_feature' }
   })
   ```

3. **Adding Insights**
   ```typescript
   // Insights are generated automatically
   // But you can trigger checks
   const { checkCompliance } = useAccessibility()
   await checkCompliance()
   ```
