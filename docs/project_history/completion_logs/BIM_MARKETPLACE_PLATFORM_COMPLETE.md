## 📝 **USAGE EXAMPLES**

### **Create Marketplace Listing**
```typescript
const marketplaceService = getBIMMarketplaceService()
const listing = await marketplaceService.createListing('provider-id', {
  type: 'model',
  title: 'Warehouse BIM Model',
  description: 'Complete warehouse BIM model',
  category: 'architectural',
  pricing: { model: 'one-time', amount: 99.99, currency: 'USD' },
  // ... other fields
})
```

### **Run AI Analysis**
```typescript
const aiService = getBIMAIAnalysisService()
const analysis = await aiService.runClashDetection('model-id', {
  tolerance: 0.1,
  systems: ['structural', 'mep'],
})
```

### **Start Collaboration**
```typescript
const collabService = getBIMCollaborationService()
const session = await collabService.createSession('model-id', 'user-id', 'User Name', {
  name: 'Design Review',
  settings: {
    allowGuestAccess: true,
    chatEnabled: true,
    annotationsEnabled: true,
  },
})
```
