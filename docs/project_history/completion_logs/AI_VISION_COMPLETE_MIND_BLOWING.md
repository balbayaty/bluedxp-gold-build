## 🎯 **USAGE EXAMPLES**

### **1. Unified Analysis (All Features):**
```typescript
import unifiedVisionService from '@/lib/services/ai/unifiedVisionService'

const result = await unifiedVisionService.analyze(
  imageFile,
  'Context',
  {
    module: 'wms',
    enableObjectTracking: true,
    enableAnomalyDetection: true,
    enableSceneUnderstanding: true,
    enableVideoAnalysis: true,
  }
)
```

### **2. Industry-Specific:**
```typescript
// Manufacturing
import manufacturingVisionService from '@/lib/services/ai/industry/manufacturingVisionService'
const result = await manufacturingVisionService.analyzeManufacturingImage(
  imageFile,
  'Quality control inspection',
  { mode: 'defect_detection' }
)

// Logistics
import logisticsVisionService from '@/lib/services/ai/industry/logisticsVisionService'
const result = await logisticsVisionService.analyzeLogisticsImage(
  imageFile,
  'Package damage assessment',
  { mode: 'damage_assessment' }
)

// Healthcare
import healthcareVisionService from '@/lib/services/ai/industry/healthcareVisionService'
const result = await healthcareVisionService.analyzeHealthcareImage(
  imageFile,
  'Equipment verification',
  { mode: 'equipment_verification' }
)
```

### **3. Real-Time Streaming:**
```typescript
import streamingVisionService from '@/lib/services/ai/streamingVisionService'

const streamId = await streamingVisionService.startStreamAnalysis({
  source: {
    type: 'rtsp',
    url: 'rtsp://camera.example.com/stream',
    name: 'Camera 1',
  },
  analysisMode: 'safety',
  enableObjectTracking: true,
  enableAnomalyDetection: true,
})

// Get real-time analysis
const analysis = streamingVisionService.getStreamAnalysis(streamId)
```

### **4. Scene Understanding:**
```typescript
import sceneUnderstandingService from '@/lib/services/ai/sceneUnderstandingService'

const result = await sceneUnderstandingService.understandScene(
  imageFile,
  'Warehouse scene analysis'
)
// Returns: scene type, spatial relationships, activities, context
```

### **5. Edge Computing:**
```typescript
import edgeVisionService from '@/lib/services/ai/edgeVisionService'

const result = await edgeVisionService.analyzeWithEdge(
  imageFile,
  'Context',
  {
    useLocalModels: true,
    useCloudFallback: true,
    maxLatency: 2000,
    offlineMode: false,
  }
)
```
