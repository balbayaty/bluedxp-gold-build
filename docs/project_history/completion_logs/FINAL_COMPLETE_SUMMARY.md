## 🚀 Quick Start

### Automated Setup
```bash
# Windows
npm run setup:windows

# Linux/Mac
npm run setup
```

### Manual Setup
1. Install dependencies: `npm install`
2. Configure: Copy `.env.example` to `.env.local`
3. Start services: `docker-compose up -d`
4. Setup database: `npm run prisma:migrate`
5. Initialize: `npm run init:services`
6. Start app: `npm run dev`

### Validation
```bash
# Check dependencies
npm run check:deps

# Validate setup
npm run validate:setup

# Assess production readiness
npm run assess:production
```
