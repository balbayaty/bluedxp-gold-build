## 📋 **How to Use**

### **Quick Start (Intelligent Mode)**

1. **Navigate to**: `/brand-messaging`
2. **Select Module**: Choose from dropdown (e.g., "Warehouse Management")
3. **See Capabilities**: View routes, components, services
4. **Select Feature** (optional): Click on a feature button
5. **Choose Message Type**: Or use quick actions
6. **Generate**: Click "Generate Message"

### **Manual Mode**

1. **Toggle to Manual**: Click "Manual" button
2. **Enter Details**: Fill in all fields manually
3. **Full Control**: Customize everything
4. **Generate**: Create message with custom context

## 🔧 **API Endpoints**

### **Get Modules**
```
GET /api/modules/list
```
Returns all enabled modules with capabilities.

### **Generate Message**
```
POST /api/brand-messaging/generate
```
Generates on-brand, bilingual messaging.
