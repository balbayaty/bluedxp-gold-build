### **Europe to Middle East Patterns**

1. **Europe → Saudi Arabia (Sea)**
   ```
   Origin Facility (POL)
   → Export Customs
   → Port of Loading
   → Port of Transit (optional)
   → Port of Discharge
   → Import Customs
   → Destination Facility (POD)
   ```

2. **Europe → UAE (Air)**
   ```
   Origin Facility
   → Export Customs
   → Airport of Departure (AOD)
   → Airport of Transit (optional)
   → Airport of Arrival (AOA)
   → Import Customs
   → Destination Facility
   ```
