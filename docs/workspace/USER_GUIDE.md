# Workspace Module - User Guide

## Overview

The Workspace module provides an intelligent, dynamic workspace where users can customize their dashboard with widgets, layouts, and integrations based on their role and subscription.

## Getting Started

### Accessing Your Workspace

1. Navigate to `/workspace` in the application
2. Your default workspace layout will load automatically
3. If no layout exists, you'll see a prompt to create one

### Creating a Layout

1. Click "Create Layout" or "Add Widget"
2. Browse the widget library
3. Select widgets to add to your workspace
4. Arrange widgets by dragging and resizing (in edit mode)
5. Click "Save Layout" to persist your changes

### Adding Widgets

1. Click "Add Widget" in the toolbar
2. Browse widgets by category or search
3. Click on a widget to add it to your current layout
4. Widgets are automatically positioned, but you can move them

### Customizing Widgets

1. Enter edit mode by clicking "Edit" in the toolbar
2. Drag widgets to reposition
3. Resize widgets using the corner handle
4. Click the settings icon on a widget to configure it
5. Changes are auto-saved

### Layout Management

- **Save Layout**: Automatically saves when you make changes
- **Set Default**: Right-click a layout to set as default
- **Duplicate**: Create a copy of an existing layout
- **Delete**: Remove layouts you no longer need

## Integrations

### Google Workspace

1. Go to Workspace Settings
2. Click "Connect Google Workspace"
3. Authorize access to Calendar, Drive, Gmail, and Tasks
4. Widgets will automatically appear for connected services

**Available Widgets:**
- Google Calendar: Upcoming events and meetings
- Google Drive: Recent files and quick access
- Gmail: Inbox preview and unread count
- Google Tasks: Task list and completion tracking

### Email Integration

1. Go to Workspace Settings
2. Click "Add Email Account"
3. Select your email provider (Gmail, IMAP, POP3, Outlook, Custom SMTP)
4. Enter credentials
5. Email widget will appear in your workspace

**Features:**
- Unified inbox for all connected accounts
- Unread count badges
- Email preview and quick actions
- AI-powered categorization

## Troubleshooting

**Widget not loading?**
- Check your permissions for the widget's module
- Verify the widget's data source is accessible
- Try refreshing the widget manually

**Layout not saving?**
- Check your browser's local storage
- Verify you have permission to save layouts
- Try refreshing the page

**Integration not working?**
- Verify credentials are correct
- Check integration status in settings
- Try disconnecting and reconnecting
