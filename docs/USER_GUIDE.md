## 📦 Core Features

### Schrödinger's Truck Quantum Logistics

**What it does:** Predicts shipment delivery outcomes using quantum-inspired probability calculations.

**How to use:**
1. Navigate to Transportation → Shipments
2. Select a shipment
3. View quantum state (COMMITTED, CONTINGENT, or PHANTOM)
4. See probability breakdown (on-time, delayed, no-show)
5. Monitor real-time updates as events occur

**Understanding States:**
- **COMMITTED** (>70% on-time): High confidence delivery
- **CONTINGENT** (40-70%): Conditional on factors
- **PHANTOM** (<40%): High risk of delay/no-show

---

### Evidence Packet System

**What it does:** Creates tamper-evident evidence packets for legal and compliance purposes.

**How to use:**
1. Navigate to Compliance → Evidence Packets
2. Click "Generate Packet"
3. Select entity type and ID
4. Review generated packet
5. Verify integrity anytime
6. Generate court-ready format when needed

**Features:**
- Merkle tree integrity verification
- Contradiction detection
- Legal hold capability
- Court-ready formatting

---

### Saudi Alignment Engine

**What it does:** Tracks alignment with Saudi Vision 2030 and regulatory compliance across 17 government agencies.

**How to use:**
1. Navigate to Compliance → Saudi Alignment
2. View Vision 2030 alignment score
3. Check regulatory compliance by agency
4. Review compliance score and risk level
5. Generate compliance reports

**Agencies Tracked:**
- TGA, MOT, ABSHER, NAFATH, SABER
- SFDA, ZATCA, SAMA, NCSC, SDAIA
- SASO, MODON, MOC, MOI, MOMRA, MISA, CITC

---

### Corridor Intelligence

**What it does:** Analyzes and optimizes logistics corridors (Saudi-Kuwait, Saudi-Syria).

**How to use:**
1. Navigate to Transportation → Corridors
2. Select a corridor
3. View analysis (delay patterns, bottlenecks)
4. Review optimization recommendations
5. Track touchpoint performance

**Features:**
- 12 touchpoint tracking (Saudi-Kuwait)
- Delay pattern analysis
- Bottleneck identification
- Optimization recommendations

---

### Geofence System

**What it does:** Tracks shipments entering/exiting defined zones with automatic notifications.

**How to use:**
1. Navigate to Transportation → Geofence
2. Create zones (warehouses, checkpoints, etc.)
3. Define zone boundaries
4. Set expected/max dwell times
5. Receive automatic notifications on entry/exit

**Zone Types:**
- Warehouse
- Customer Site
- Checkpoint
- Border Crossing
- Rest Area
- Fuel Station
