### 🚀 Quick Start

**1. Run Setup:**
```bash
# Windows
npm run setup:user-management:ps1

# Linux/macOS
npm run setup:user-management:sh

# All Platforms
npm run setup:user-management
```

**2. Seed Data (Optional):**
```bash
npm run seed:user-management
```

**3. Start Application:**
```bash
npm run dev
```

**4. Access UI:**
Visit: **http://localhost:3002/settings/users**
