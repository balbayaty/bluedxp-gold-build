## 📐 ARCHITECTURE GUIDELINES

### BlueDXP Patterns to Follow:
1. **Event-Driven Architecture**: Use Event Bus for communication
2. **CQRS Pattern**: Use Event Store for read/write separation
3. **Service Layer Pattern**: Business logic in services
4. **Adapter Pattern**: External integrations via adapters
5. **Module Registry**: Proper module registration
6. **Multi-Tenant**: Tenant isolation in all operations
7. **RBAC**: Role-based access control
8. **Security First**: Input validation, output sanitization

### Code Quality Standards:
- TypeScript strict mode
- No `any` types (use `unknown` if needed)
- Comprehensive error handling
- Input validation
- Output sanitization
- Audit logging
- Performance optimization
