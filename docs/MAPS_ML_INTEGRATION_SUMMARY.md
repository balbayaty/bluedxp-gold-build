## 🔑 **API KEY SETUP**

Add to `.env`:
```bash
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_key
NEXT_PUBLIC_MAPBOX_API_KEY=your_key
```

**Get Keys**:
- Google: https://console.cloud.google.com/google/maps-apis
- Mapbox: https://account.mapbox.com/access-tokens/
