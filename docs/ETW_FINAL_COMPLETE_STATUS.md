## 🚀 Deployment Steps

### ⚠️ IMPORTANT: Stop Dev Server First

1. **Stop Development Server**

2. **Generate Prisma Client**:
   ```bash
   npx prisma generate
   ```

3. **Create Migration**:
   ```bash
   npx prisma migrate dev --name add_etw_models
   ```

4. **Restart Server**:
   ```bash
   npm run dev
   ```

5. **Verify**:
   ```bash
   npm run verify:etw
   ```

6. **Test**:
   - Navigate to: `http://localhost:3002/etw`
   - Create an ETW
   - Test all features
