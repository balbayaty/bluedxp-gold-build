```typescript
await unifiedEmotionalIntelligenceService.analyzeSentiment(
  text,
  { entityId, entityType, language: 'ar' }
)
```

### **2. Emotional State Tracking**
```typescript
await unifiedEmotionalIntelligenceService.trackEmotionalState(
  entityId,
  entityType,
  emotionalState,
  sentiment
)
```

### **3. Behavioral Prediction**
```typescript
await unifiedEmotionalIntelligenceService.predictBehavior(
  entityId,
```
