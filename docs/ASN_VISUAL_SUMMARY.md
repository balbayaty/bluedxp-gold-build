## 🚀 **All API Endpoints**

### Core Operations
```
GET    /api/asn                    # List all ASNs
POST   /api/asn                    # Create ASN
GET    /api/asn/[id]               # Get ASN
PUT    /api/asn/[id]               # Update ASN
DELETE /api/asn/[id]               # Delete ASN
POST   /api/asn/[id]/status        # Update status
```

### Analytics & AI
```
GET    /api/asn/analytics          # Get analytics
GET    /api/asn/[id]/insights      # AI insights
GET    /api/asn/ai/predictive      # Predictive analytics
```

### Export & Real-Time
```
POST   /api/asn/export             # Export (Excel/PDF/CSV)
GET    /api/asn/realtime           # SSE stream
```

### Knowledge & Evidence
```
GET    /api/asn/[id]/knowledge     # Knowledge articles
GET    /api/asn/knowledge/search   # Search knowledge
GET    /api/asn/[id]/evidence      # Get evidence
POST   /api/asn/[id]/evidence      # Create evidence
```
