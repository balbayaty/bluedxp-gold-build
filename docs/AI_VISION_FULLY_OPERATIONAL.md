## 📊 **DATABASE TABLES**

### **1. vision_analyses**
- Stores all vision analysis results
- **Records:** Analysis data, images, compliance scores
- **Indexed:** tenantId, userId, analysisId, module, createdAt

### **2. vision_learning_patterns**
- Stores learned patterns from feedback
- **Records:** Visual features, confidence, accuracy, rules
- **Indexed:** tenantId, patternId, analysisId, lastSeen

### **3. vision_learning_feedback**
- Stores user feedback and corrections
- **Records:** User corrections, validation status, learning impact
- **Indexed:** tenantId, patternId, analysisId, recordId

### **4. vision_history**
- Stores complete audit trail
- **Records:** Actions, changes, previous states
- **Indexed:** tenantId, analysisId, userId, action, createdAt

### **5. vision_metrics**
- Stores analytics and metrics
- **Records:** Daily/weekly/monthly aggregations
- **Indexed:** tenantId, date, period
