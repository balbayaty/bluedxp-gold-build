# 🏪 Marketplace User Guide

## Overview

The BlueDXP Marketplace is a comprehensive platform for finding and booking logistics and professional services including storage, transportation, freight, consulting, manpower, and translation services.

---

## Getting Started

### For Service Seekers

#### 1. **Search for Services**

- Navigate to `/marketplace` or `/marketplace/search`
- Use the search bar to find services by keyword
- Filter by:
  - **Category**: Storage, Transportation, Freight, Consulting, etc.
  - **Location**: City or region
  - **Price Range**: Set minimum and maximum budget
  - **Rating**: Filter by provider ratings (4+ stars, etc.)

#### 2. **View Service Listings**

- Click on any service listing to see:
  - Detailed description
  - Pricing information
  - Provider information and ratings
  - Availability calendar
  - Reviews from other customers

#### 3. **Create a Booking**

1. Click "Book Now" on a listing
2. Fill in your requirements:
   - **Timeline**: Start and end dates
   - **Capacity/Quantity**: Amount needed
   - **Location**: Specific address if needed
   - **Special Requirements**: Any additional needs
3. Review pricing breakdown
4. Submit booking request

#### 4. **Manage Bookings**

- View all bookings at `/marketplace/bookings`
- Filter by status (Pending, Confirmed, In Progress, Completed)
- Track booking progress
- Communicate with providers via messaging
- Submit reviews after completion

---

### For Service Providers

#### 1. **Register as Provider**

1. Navigate to `/marketplace/providers/register`
2. Fill in company information:
   - Company name and registration
   - Contact details
   - Services offered
   - Certifications and licenses
3. Submit for verification

#### 2. **Create Service Listings**

1. Go to Provider Dashboard (`/marketplace/providers/dashboard`)
2. Click "Create New Listing"
3. Select service category
4. Fill in details:
   - Title and description
   - Pricing structure
   - Availability
   - Location and coverage area
   - Capacity/limits
5. Upload photos/documents
6. Publish listing

#### 3. **Manage Listings**

- View all listings in Provider Dashboard
- Edit listing details
- Update pricing and availability
- View analytics and performance metrics

#### 4. **Handle Bookings**

- View booking requests at `/marketplace/providers/bookings`
- Accept or decline bookings
- Update booking status
- Communicate with customers
- Generate invoices
- Track payments
