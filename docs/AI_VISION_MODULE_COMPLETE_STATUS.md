## 📊 **DATABASE SCHEMA**

### **VisionAnalysis Table**
```sql
- id (PK)
- analysisId (UNIQUE)
- tenantId (INDEXED)
- userId (INDEXED)
- imageUrl, thumbnailUrl, fileUrl
- analysis (JSONB) - Full analysis result
- analysisMode, provider, model
- totalIssues, criticalIssues
- complianceScore, isCompliant
- relatedRecordId, relatedRecordType
- metadata, tags
- createdAt, updatedAt
```

### **VisionPattern Table**
```sql
- id (PK)
- patternId (UNIQUE)
- tenantId (INDEXED)
- name, description
- visualFeatures (JSONB)
- confidence, occurrenceCount, accuracy
- firstSeen, lastSeen
- autoGeneratedRules (JSONB)
- preventionSuggestions (JSONB)
- analysisId (FK -> VisionAnalysis)
```

### **VisionFeedback Table**
```sql
- id (PK)
- tenantId (INDEXED)
- patternId (FK -> VisionPattern)
- analysisId (FK -> VisionAnalysis)
- userCorrection (JSONB)
- validated, validatedBy, validatedAt
- learningImpact (JSONB)
```

### **VisionHistory Table**
```sql
- id (PK)
- analysisId (FK -> VisionAnalysis, CASCADE)
- action (created/updated/viewed/deleted)
- changes (JSONB)
- previousState (JSONB)
- createdAt
```

### **VisionMetrics Table**
```sql
- id (PK)
- tenantId, date, period
- totalAnalyses, totalIssues, criticalIssues
- averageScore, averageTime
- byModule (JSONB)
- byAnalysisType (JSONB)
```
