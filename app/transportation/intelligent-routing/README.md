# Intelligent Routing - Employee Quick Start Guide

## 🚀 **GETTING STARTED**

### **Access the Feature**
1. Navigate to **Transportation** → **Intelligent Routing** in the main menu
2. Or go directly to: `/transportation/intelligent-routing`

### **What You Can Do**

#### **1. Plan Intelligent Routes**
- Click on **Route Planning** tab
- Enter origin and destination
- Select transport mode
- Enter cargo details
- Select compliance programs (if enrolled)
- Click **Plan Intelligent Route**

**The system will:**
- ✅ Find all constraints (truck bans, opening hours, etc.)
- ✅ Calculate actual transit time
- ✅ Recommend compliance programs
- ✅ Show route score and feasibility
- ✅ Provide alternative routes if needed

#### **2. Calculate Transit Time**
- Click on **Transit Time Calculator** tab
- Enter route details
- Select compliance programs
- Click **Calculate Transit Time**

**The system will:**
- ✅ Calculate base transit time
- ✅ Add constraint delays
- ✅ Apply compliance program benefits
- ✅ Show predictions (optimistic/realistic/pessimistic)
- ✅ Provide recommendations and warnings

## 📋 **STEP-BY-STEP GUIDE**

### **Planning Your First Route**

1. **Enter Origin**
   - Type city name or full address
   - System will geocode automatically

2. **Enter Destination**
   - Type city name or full address

3. **Select Transport Mode**
   - Road, Air, Sea, or Rail

4. **Enter Cargo Details**
   - Weight (kg)
   - Volume (m³)
   - Check if hazmat or temperature-controlled

5. **Select Compliance Programs** (if enrolled)
   - AEO, Golden List, TIR, etc.
   - These reduce processing times

6. **Set Preferences**
   - Avoid truck bans
   - Minimize cost
   - Prioritize fastest

7. **Click "Plan Intelligent Route"**

8. **Review Results**
   - See transit time breakdown
   - Check constraints
   - Review compliance program recommendations
   - View route score

---

## 💡 **TIPS FOR BEST RESULTS**

1. **Use Compliance Programs**
   - If enrolled in AEO, Golden List, or TIR, select them
   - Can save hours of processing time

2. **Check Constraints**
   - Click on any constraint to see details
   - Understand what's causing delays

3. **Review Recommendations**
   - System suggests compliance programs
   - Follow recommendations to optimize routes

4. **Compare Routes**
   - System shows alternative routes if needed
   - Compare scores and transit times

## ❓ **FREQUENTLY ASKED QUESTIONS**

**Q: Why is my transit time longer than expected?**  
A: The system considers ALL constraints including truck bans, facility hours, government agency hours, and processing times. This gives you realistic estimates.

**Q: How do compliance programs help?**  
A: Programs like AEO and Golden List can reduce processing times by 30-50% and eliminate certain restrictions.

**Q: Can I save routes?**  
A: Yes, use the Route Data Input Form to save routes for future use.

**Q: What if a route is not feasible?**  
A: The system will show alternative routes and explain why the route isn't feasible.
